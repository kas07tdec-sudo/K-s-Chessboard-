# 🪵 K's Chessboard ! — GOATed Edition ♟️

A feature-packed, production-grade web chess studio built with pure **Vanilla JavaScript (ES6+)**, **HTML5**, **CSS3**, **TensorFlow.js**, **PeerJS (WebRTC)**, and the **Web Audio / Speech APIs**.

Designed with dynamic mahogany wood, cyberpunk, and royal marble themes, native acoustic audio synthesis, a 3-ply Minimax AI engine, online peer-to-peer multiplayer, and real-time machine learning playstyle tracking — deployed seamlessly on **Vercel**.

## ✨ Key Features

- **🧠 Multi-Level Minimax AI Engine:**
  - **Easy:** Casual play with randomized legal move selection.
  - **Medium:** Material-focused tactical evaluator.
  - **Hard:** **Minimax Engine with Alpha-Beta Pruning** searching 3 moves deep.
- **📊 Real-Time Evaluation Bar & Move Quality Badges:**
  - Dynamic positional/material evaluation sidebar.
  - Automatic move classification: **BEST** 🟢, **GOOD** 🔵, **INACCURACY** 🟡, and **BLUNDER** 🔴.
- **🤖 TensorFlow.js Playstyle ML Analytics:**
  - Tracks move aggression ratios, pawn structures, and playstyle profiles in real-time.
- **🌐 PeerJS WebRTC Online Multiplayer:**
  - Connect with friends using direct peer-to-peer room codes without needing a backend server.
- **🎙️ Web Speech API Announcer & Voice Control:**
  - Voice announcements for checks and blunders, plus hands-free voice command recognition (e.g., *"e2 to e4"*).
- **🧩 Daily Tactical Puzzles Mode:**
  - Integrated "Tactics Trainer" mode featuring predefined mate-in-1 and mate-in-2 tactical drills.
- **🎆 Canvas Particle Explosions & Board Shake FX:**
  - Visual spark particle effects on piece captures and screen-shake feedback on checks and checkmates.
- **⏱️ Chess Clocks & FEN/PGN Integration:**
  - Blitz (3m), Rapid (10m), and Classical (15m) timers.
  - PGN move notation clipboard export and FEN board state loader.
- **🏆 LocalStorage Profile & Achievements:**
  - Persistent stat tracking with unlockable badges (*Grandmaster Slayer, Speed Demon, Tactics Scholar*).
- **🔊 Acoustic Sound Synthesizer:**
  - Custom Web Audio API sound generator creating authentic impact sounds without external audio file dependencies.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Grid/Flexbox/CSS Variables), Vanilla JavaScript (ES6+)
- **Machine Learning:** TensorFlow.js
- **Networking:** PeerJS (WebRTC)
- **Audio & Speech:** Native Web Audio API & Web Speech API
- **Deployment:** Vercel CLI
